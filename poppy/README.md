# poppy

Runtime for [Poppy](https://github.com/hnerdrum/poppy): query and write through a generated Client.

Write a **Schema**, run **poppy-codegen** to emit table types and a Client, then import this package from application code.

The getting-started walkthrough, limits, and the Task example live in the [repository README](https://github.com/hnerdrum/poppy#readme).
